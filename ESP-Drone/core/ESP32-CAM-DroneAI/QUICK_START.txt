📋 WHAT'S NEW:
  • ESP32-CAM now connects to your WiFi network

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 STEP 1: BUILD & FLASH (5 minutes)

  1. Open ESP-IDF Command Prompt
  2. Navigate to project folder
  3. Run: idf.py build
  4. Connect ESP32-CAM via USB
  5. Run: idf.py -p COM3 flash monitor
     (Replace COM3 with your serial port)
  6. WAIT for logs to show:
     ✅ ESP32-CAM Drone Ready!
     🌐 IP Address: 192.168.x.x
  7. COPY the IP address

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🐍 STEP 2: SETUP PYTHON (2 minutes)

  1. Open Command Prompt
  2. Run: pip install -r requirements.txt
     (Or: pip install opencv-python requests numpy)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📹 STEP 3: STREAM VIDEO (1 minute)

  Replace 192.168.x.x with the IP from Step 1

  ✓ Display live video:
    python fetch_video.py 192.168.x.x

  ✓ Save to file:
    python fetch_video.py 192.168.x.x --output video.mp4

  ✓ Test connection:
    python fetch_video.py 192.168.x.x --test

  ✓ Capture 300 frames:
    python fetch_video.py 192.168.x.x --frames 300

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⌨️  CONTROLS:

  While streaming:
    • Press 'q' to quit
    • Ctrl+C to force stop

    → Verify IP address is correct
    → Ensure both on same WiFi network

    → Run: pip install opencv-python
