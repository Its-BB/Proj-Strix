# Dataset Summary (Clean Package)

This cleaned package does not include raw training images/labels.

The following split statistics are retained from the training run used for
the paper:

- Classes: `knife`, `pistol` (2 classes)
- Train: 4409 images / 4409 labels
- Validation: 1043 images / 1043 labels
- Test: 385 images / 385 labels

Training configuration and metrics are preserved in:

- `results/weapon_detection2/args.yaml`
- `results/weapon_detection2/results.csv`
